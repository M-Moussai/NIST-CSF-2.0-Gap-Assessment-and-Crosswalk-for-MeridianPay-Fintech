Portfolio# NIST CSF 2.0 Portfolio — MeridianPay Financial Services

A GRC portfolio applying the **NIST Cybersecurity Framework (CSF) 2.0** to a fictional cross-border payments fintech, MeridianPay Financial Services. Built to demonstrate practical GRC skills: framework interpretation, gap/maturity assessment, cross-framework mapping, and third-party risk management.

## About the fictional company

MeridianPay Financial Services is a UAE-based cross-border payments and remittance fintech, invented for this portfolio to give each project a consistent, realistic scenario. Full profile: [`company-profile.md`](./company-profile.md).

- **Industry:** Cross-border payments & remittance fintech
- **HQ:** DIFC, Dubai, UAE
- **Size:** ~350 employees | ~$45M annual revenue
- **Founded:** 2016
- **Why NIST CSF:** A new US banking partnership and cyber insurance renewal both require MeridianPay to demonstrate a cybersecurity risk management program aligned to NIST CSF 2.0.

## Projects

| # | Project | Description | Status |
|---|---|---|---|
| 01 | [Gap / Maturity Assessment](./01-gap-assessment) | All 106 NIST CSF 2.0 subcategories assessed against MeridianPay's current state, scored 0–4, with prioritized recommendations | ✅ Complete |
| 02 | Framework Crosswalk (NIST CSF ↔ ISO 27001) | Maps CSF 2.0 subcategories to ISO 27001:2022 Annex A controls | 🔄 In progress |
| 03 | Vendor / Third-Party Risk Assessment | Risk-tiers MeridianPay's key vendors and applies CSF's Supply Chain Risk Management (GV.SC) category | 🔄 In progress |

## Methodology

Each project uses the official **NIST CSF 2.0 Implementation Examples** (NIST, Feb 2024) as the reference standard for "what good looks like," then evaluates MeridianPay's fictional baseline against it.
